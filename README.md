# Aplikasi Kalkulator PHP

Aplikasi kalkulator sederhana berbasis PHP yang memiliki tampilan Web interaktif dan antarmuka Terminal (CLI).

## Fitur
- Operasi dasar: Penjumlahan, Pengurangan, Perkalian, Pembagian.
- Operasi lanjutan: Modulus (sisa bagi) dan Perpangkatan.
- Riwayat perhitungan otomatis.
- Tampilan Web yang modern & responsif.
- Versi CLI untuk dijalankan via Terminal.

## Cara Menjalankan

### 1. Mode Web (Server Lokal PHP)
Jalankan perintah berikut di terminal/command prompt pada direktori proyek:
```bash
php -S localhost:8000
